# Support

FactoryOS is maintained as a public portfolio project without a service-level agreement or guaranteed support response.

- Use the bug-report template for reproducible defects.
- Use the feature-request template for proposed improvements.
- Use private vulnerability reporting for security concerns.
- Review the [README](README.md) for installation, controls, architecture, and deployment guidance.

Do not submit proprietary production data, credentials, private employer information, or safety-critical operating questions.
